What runs where?

This website hosts downloads and instructions. It cannot run Docker or ROS on GitHub Pages. After local installation, the launcher opens http://localhost:15080 on your own PC. That local app shows actual simulated car/ROS state, not a prerecorded animation or a remote vehicle.

The setup is independent of the existing AutoDRIVE benchmark and the physical-car ROS packages. It uses a private Docker network and ROS domain 77, with no physical VESC/CAN/serial devices passed through. No host ROS or hardware GPU/Vulkan is required for this CPU/2D browser view.

Simulation only. Never use this controller to command a physical car. Supplied track prior + Gym odometry following is not fresh SLAM, unknown-track exploration or LiDAR-only autonomy.

Windows setup

  1. Have Ubuntu WSL and Docker Desktop with Linux containers/Ubuntu integration available.
  2. Extract the full offline kit or source ZIP into a writable folder.
  3. Inside RoboRacer_F1TENTH, double-click START_F1TENTH.bat. It loads/builds the image as needed and opens the local app.
  4. Use STOP_F1TENTH.bat or the red local-app STOP button. No ROS commands need to be typed.

The original Capstone workspace also has convenience buttons RUN_F1TENTH.bat and STOP_F1TENTH.bat. The extracted standalone kit uses its inside-folder Start/Stop names. Keep the launcher window running/minimised; closing it expires the host lease and stops this sandbox.

The local UI has the 23-track selector, actual vehicle/trail, optional sampled actual LiDAR, zoom/pan and a Follow vehicle option. In a narrow window, scroll below the controls to see the map. Select a track and press Start/load; the prior session is stopped first. STOP cancels pending starts and requires a new explicit Start.

Native Ubuntu / another PC

  1. Transfer/extract the offline archive into a writable Linux home directory. Keep the entire folder together.
  2. Use a native x86_64 Linux PC with Docker access, Python 3.10+ and a browser. No host ROS or GPU driver is required by this 2D setup.
  3. Run INSTALL_LINUX_SHORTCUTS.sh as a program, allowing executable permission if your file manager asks.
  4. Press Super and find RoboRacer F1TENTH Start / STOP. First launch loads the included image and opens the local view.
The setup was exercised on Windows + Ubuntu WSL + Linux Docker. Native Ubuntu on the other PC has not been driven/GUI-tested here. Rehearse driving and STOP on that PC before presenting. The source-only ZIP requires internet for the first image build.

Actual validation — not a new AutoDRIVE record

All 23 maps passed map/line/clearance data checks. Only Melbourne has driven-lap validation here. Its supplied centreline is approximately 474.20 m; the supplied wall-hugging raceline did not meet the chosen tracking allowance, and the selection/reason is recorded.

Actual in-motion Windows STOP verified stationary disarming. An independent read-only ROS observer received genuine 1,080-beam scans, odometry, map and native state without sending motor commands. A controlled real simulated wall collision after 65 seconds verified standstill, one upstream reset, a lower pace and 8.060 m of resumed travel; it claims no lap and is disabled in normal launchers. STOP also cancelled a queued Monza start with no later arming.

Stock physics source, 0.01 s RK4 timestep and vehicle parameters remain. --max-speed 0 means no extra flat software ceiling; the stock physical maximum is 20 m/s, and the initial pace is 70% of a stock-derived profile. Eligible clean laps require actual gate/native-counter progress, travel/coverage and simulation/wall-time agreement. Collisions, partial laps and failures remain recorded.

Do not compare these times with AutoDRIVE's 5.8218-second lap: the track, length, dynamics, controller and clock context differ. This is also not physical-car safety or LiDAR-only autonomy validation.

Sources, licenses and attribution

F1TENTH Gym and the ROS bridge retain their MIT licenses. The supplied racetrack repository is GPL-3.0; its complete data/source/license and upstream attribution are included. Source/image hashes and exact commits are pinned. The wrapper adapts the legacy Gym API, ROS declarations and publication scheduling; it does not edit the physics source or original maps.

The racetrack project attributes its original database to Alexander Heilmeier / TUM and its original centreline data to OpenStreetMap. Retain those notices and the upstream citation when redistributing. Download the attribution notes.
