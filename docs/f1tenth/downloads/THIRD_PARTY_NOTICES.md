# Upstream sources and map attribution

This is a separate F1TENTH simulation setup, not the AutoDRIVE IROS practice simulator.

- `vendor/f1tenth_gym`: https://github.com/f1tenth/f1tenth_gym — MIT license; full upstream physics sources and license retained.
- `vendor/f1tenth_gym_ros`: https://github.com/f1tenth/f1tenth_gym_ros — MIT license; upstream ROS bridge source and license retained.
- `vendor/f1tenth_racetracks`: https://github.com/f1tenth/f1tenth_racetracks — GPL-3.0 license; original maps, centreline/raceline data and license retained. These are supplied third-party maps, not maps generated by this project.

Exact commits and source/input checksums are recorded in `SOURCE_LOCK.json`.
No simulator physics, original map pixels, map resolution or map origin are edited.
Gym 0.23.1's API wrapper is removed when constructing the legacy bridge environment
so the upstream positional-reset API works; this does not replace its physics.
Pyglet/Xvfb handles the upstream OpenGL import. The application browser is a
separately labelled 2D rendering of actual simulation state, not a Unity scene.

The racetrack repository attributes its source track database to Alexander
Heilmeier / the Institute of Automotive Technology, Technical University of Munich,
and original centreline data to OpenStreetMap. Preserve the upstream attribution,
licenses and citation when redistributing map data. Its supplied racelines are
minimum-curvature priors; their speed columns are not physical-car validation.

Suggested upstream citation: Betz et al., “Autonomous Vehicles on the Edge: A Survey
on Autonomous Vehicle Racing,” IEEE Open Journal of Intelligent Transportation
Systems 3 (2022), 458–488, doi:10.1109/OJITS.2022.3181510.
