Single-file simulator benchmark

The latest custom simulator launcher, controller, planner, lap logger, adaptive tuner and watchdog are consolidated in ONEFILE_RACER.py. The historical best eligible clean full lap is 5.8218 seconds; nine later bounded candidates did not beat it. The five-second target remains unachieved.

This is a separate simulator-pose-assisted benchmark using genuine previously recorded track memory, with no imposed command-speed ceiling. Physical/model constraints remain; crash-stop and proximity/predictive governors are disabled, while STOP, stale-data and liveness checks remain. It is not physical-car or LiDAR-only validation. Native Ubuntu driving remains unverified.

Project Goal

The car is designed to be placed on an unknown closed track, create a map while driving, determine the drivable corridor from live LiDAR data, complete a lap autonomously, remember the track, and improve subsequent laps.

Perception

Hokuyo 2D LiDAR provides the live /scan stream used by both localisation and reactive track detection.

Localisation + Mapping

RF2O produces laser odometry while SLAM Toolbox builds a live occupancy-grid map.

Autonomous Control

A LiDAR gap detector and race controller generate steering and speed commands for the physical car.

Safety

An independent safety supervisor and manual master enable sit in front of the final Autoware-to-VESC command path.

Track Memory

The first lap is recorded and used to generate a learned path for later laps.

Physical Platform

NVIDIA Jetson Orin Nano, Hokuyo LiDAR, VESC 6 MK VI, brushless motor and steering servo.

Physical Testing

The vehicle is tested in stages: software-only checks, wheels-up actuator validation, low-speed ground testing, measured braking and steering validation, then progressive speed increases.

The vehicle should always start disarmed. Keep a manual stop/disarm method available during physical testing.
